# 市场的长镜头｜三次科技革命的股市曲线

这是一份**完整、无需外部依赖的静态网站**，已包含这段对话里制作的 **7 张原始图表**。

## 网站目录

- `index.html`：网站页面与全部图表说明
- `styles.css`：响应式设计
- `script.js`：主题筛选、全屏放大、键盘前后切换、原图下载
- `assets/`：全部七张原始 PNG（不要删除或修改路径）

## 在 ChatGPT Sites 中使用

1. 在 ChatGPT 网页版选择 Work，或在 ChatGPT 桌面版使用 Work / Codex，明确要求创建 **ChatGPT Site**。
2. 上传本压缩包（或解压上传整个文件夹），让 ChatGPT 使用 `index.html`、`styles.css`、`script.js` 和 `assets/` 建站。
3. 在预览里检查 7 张图片、分类切换和放大功能，再由你选择访问范围并点击 Publish。

可直接发送给 Work / Sites 的指令：

> 请用我上传的 `tech-cycles-site.zip` 创建一个 ChatGPT Site，标题为「市场的长镜头｜三次科技革命的股市曲线」。优先复用网站现有的 HTML/CSS/JS 设计，保留 assets 文件夹中全部 7 张图，确保手机端适配、筛选分类、高清放大、下载图片等功能。先生成私有预览让我确认，**不要未经我确认就公开发布**。

注意：该文件包本身不是已经部署的 ChatGPT Site，尚无线上 URL。图表不代表投资建议。

## 数据说明

价格指数：NASDAQ Composite；归一化图表以各自起点 = 100；1987 与 2000 后的恢复指**名义价格**收复前高；AI 历史范围到 2026-10-20。
